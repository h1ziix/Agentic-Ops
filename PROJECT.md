# Agentic Ops

## Current release boundary

The stages below are historical planning. Release 0.6 extends 0.5 with a deterministic Executor, Gmail/HubSpot OAuth and exact approved messages/contact patches, plus internal follow-up plans. Approve and Execute remain separate; legacy content approvals never grant execution rights. The operational dark/light SaaS design and existing pipeline remain authoritative.

Release 0.7 owns Calendar, background continuation, scheduled retries, separately approved future follow-up dispatch, monitoring and recovery/reconciliation jobs, even where the old stages group them together. Controlled live verification is a 0.6 acceptance gate; missing consent/configuration must be reported explicitly.

## Product Definition

Agentic Ops is an agentic AI sales operations platform.

Users describe a business objective in natural language, and the platform converts it into an observable workflow that can research companies, qualify opportunities, generate outreach, request human approval, and eventually execute approved actions.

Example:

> Find 20 SaaS companies in Kazakhstan that could benefit from AI automation, research them, score the opportunities and prepare personalized outreach. Do not send anything without my approval.

Agentic Ops transforms this into:

```text
Goal
↓
Plan
↓
Company Discovery
↓
Research
↓
Qualification
↓
Lead Scoring
↓
Outreach Generation
↓
Approval
↓
Execution
↓
Follow-up
```

# Main User Journey

## 1. Create Goal

The user enters:

> Find 15 fintech companies in Kazakhstan where AI automation could improve customer support or internal operations.

## 2. Planning

Planner converts the goal into tasks.

Example:

```text
1. Define ICP
2. Search target companies
3. Research each company
4. Identify automation opportunities
5. Score companies
6. Generate personalized outreach
7. Request approval
```

## 3. Research

Research Agent gathers:

- company name
- website
- description
- industry
- location
- relevant products
- potential operational problems
- possible AI automation opportunities
- sources

## 4. Qualification

The system evaluates the company.

Example:

```text
Lead Score: 87 / 100

Opportunity:
Customer support automation

Reason:
Digital-first fintech with multiple customer-facing products
and potentially high support volume.

Confidence:
High
```

## 5. Outreach

Agent generates personalized outreach based on actual research.

The outreach should reference relevant context rather than produce generic spam.

## 6. Approval

The user sees proposed actions.

Example:

```text
18 actions waiting for approval

18 personalized emails
18 CRM contacts
18 follow-up tasks
```

The user can:

- approve
- reject
- edit
- inspect

## 7. Execution

Approved actions can later be executed using external integrations.

## 8. Follow-up

The system may later schedule follow-ups and detect whether a response was received.

# UX Principles

Agentic Ops should feel like an operational system.

The main interface is NOT a chatbot.

Natural language input is used to create workflows, but execution is shown using:

- tasks
- tables
- timelines
- logs
- status badges
- approval queues
- structured panels

The system should always answer:

1. What is the agent doing?
2. Why is it doing it?
3. What has already completed?
4. What failed?
5. What is waiting for me?
6. What will happen next?

The first serious MVP is complete when the following works:

```text
User creates goal
↓
Planner creates tasks
↓
Agent researches companies
↓
Companies appear in UI
↓
Leads are scored
↓
Outreach is generated
↓
User reviews approval
↓
User approves action
↓
Execution occurs
↓
Entire execution is visible in activity history
```

# Non-Goals For Initial Development

Do not initially build:

- full CRM replacement
- email marketing platform
- complex billing system
- multi-region architecture
- enterprise RBAC
- Kubernetes
- complex microservices
- arbitrary workflow builder
- dozens of AI agents

The focus is one extremely good workflow.
